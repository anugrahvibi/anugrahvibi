## Selected work
- **[Sentinel — SentinelPushToProd](https://github.com/anugrahvibi/SentinelPushToProd)** — Finds hidden backdoor triggers in poisoned text classifiers and verifies them against model behavior. [Earlier prototype: sentinel-ai](https://github.com/anugrahvibi/sentinel-ai).
- **[Laya-Offscript](https://github.com/anugrahvibi/Laya-Offscript)** — Open research into whether training-time poisoning creates trigger-conditioned decisions in a local Laya System-1 model and whether Sentinel-inspired detection transfers. Early probes are not evidence of a backdoor.
- **[Celestin](https://github.com/anugrahvibi/Celestin)** — Local MCP server for project-scoped messages and decisions, with searchable, budget-bounded context for AI clients.
- **[CascadeNet](https://github.com/anugrahvibi/CascadeNet)** — Team prototype modeling flood-related failures across connected infrastructure to compare emergency response and protection plans.
- **[PixelPoison](https://github.com/anugrahvibi/PixelPoison)** — Visualizes FGSM and PGD adversarial attacks against a CNN trained on MNIST.

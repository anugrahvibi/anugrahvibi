## 🔬 Research focus

I’m investigating whether training-time poisoning can create trigger-conditioned decisions in a local Laya System-1 model, and whether Sentinel-inspired detection transfers. The work is exploratory; current probes do not establish that the model contains a backdoor.

## 🧪 Selected work

### Model security & adversarial ML

- **[Sentinel — SentinelPushToProd](https://github.com/anugrahvibi/SentinelPushToProd)** — Probes text classifiers for hidden backdoor triggers and checks candidate triggers against model behavior. [Earlier prototype: sentinel-ai](https://github.com/anugrahvibi/sentinel-ai).
- **[Laya-Offscript](https://github.com/anugrahvibi/Laya-Offscript)** — Research into training-time poisoning and trigger-conditioned decisions in a local System-1 model, documented through experiments, limitations, and failures.
- **[PixelPoison](https://github.com/anugrahvibi/PixelPoison)** — Visualizes FGSM and PGD adversarial attacks against a CNN trained on MNIST.

### Tools & simulation

- **[Celestin](https://github.com/anugrahvibi/Celestin)** — Local MCP server for project-scoped messages and decisions, with searchable, budget-bounded context for AI clients.
- **[CascadeNet](https://github.com/anugrahvibi/CascadeNet)** — Team prototype modeling flood-related failures across connected infrastructure to compare emergency response and protection plans.
